## Project Overview

I designed and developed a personal portfolio website using HTML, CSS, JavaScript, and Bootstrap. The website showcases my technical skills, education, professional experience, and projects for potential employers, recruiters, and peers.

The project is divided into three main parts:

1. Content
2. Design
3. Interactivity

## Target Audience

The primary audience is potential employers and recruiters looking to learn about my technical abilities and projects. The site is also intended for peers and other people interested in my work.

## Content Strategy

I organized the content to help visitors quickly understand who I am, what technical skills I have, what I have built, and how to contact me. The homepage provides an introduction and skills overview, while separate pages provide more detail about my education, work experience, and projects.

# Part 2: Design

### 1. What overall style will best represent you (minimalist, creative, professional, etc.)?

I chose a clean, organized layout with playful details. The website reflects my personality while remaining readable and appropriate for a professional portfolio.

### 2. What color scheme will you use and why?

I used a pink color scheme with pink backgrounds, lighter pink and white content sections, and darker pink accents for headings, buttons, and links. Darker text provides contrast. I chose pink because it is my favorite color and makes the design feel personal.

### 3. What fonts will you use for headings and body text?

I used Poppins for the main website text, along with a decorative script style for my name in the header.

### 4. How will your design reflect your personality or field?

The pink color palette and decorative cat illustrations reflect my personality. The organized content, project screenshots, and technical information highlight my interest in technology and design.

### 5. What layout will your homepage follow?

The homepage has a navigation header, an introductory section, and a technical skills section. It provides links to the other pages so visitors can explore my experience and projects.

### 6. How will you organize project sections visually?

The Projects page uses Bootstrap accordions. Each project can be expanded to show screenshots, a description, my role, technologies used, key features, and a GitHub link where available. This keeps the page organized without displaying every detail at once.

### 7. Will the site be mobile-friendly? How will you ensure responsiveness?

Yes. I used CSS Flexbox, media queries, and flexible sizing. I adjusted the navigation, images, cards, and multi column layouts so content remains readable on smaller screens. For example, project screenshots stack above descriptions on mobile.

### 8. What visual hierarchy will guide visitors?

Larger headings, contrasting colors, styled buttons, and spacing help visitors identify the most important content and move through each page.

### 9. How will consistency be maintained across pages?

All pages use the same color palette, fonts, button styles, and rounded design elements.

### 10. How will accessibility be considered (contrast, font size, readability)?

I used readable font sizes, color contrast, descriptive alternative text for images, and clear navigation labels. Links and buttons use recognizable labels so visitors can understand their purpose.

### 11. Will you use icons, images, or illustrations? Why?

Yes. I used project screenshots to demonstrate my work, technical icons to represent skills and tools, a college logo in the Experience section, and decorative cat illustrations to add personality.

### 12. What portfolio websites inspired your design?

I was inspired by portfolio websites that combine simple layouts, soft colors, and illustrations. I wanted to create something creative and playful while still being professional and easy to navigate.

# Part 3: Interactivity

### 1. What interactive elements will your site include (navigation menus, buttons, forms)?

The website includes navigation links, buttons, expandable project accordions, GitHub and LinkedIn links, email contact links, and a resume link.

### 2. Will your site include a contact form? How will it work?

No. The Contact page provides direct ways to reach me through email and professional profile links rather than a contact form.

### 3. What JavaScript features will you implement?

The website uses Bootstrap's JavaScript functionality to expand and collapse project accordions. This allows visitors to explore individual projects without navigating away from the Projects page.

### 4. How will users receive feedback from interactions?

Links and buttons have hover styling, the current navigation item is visually distinguished, and project accordions visibly expand or collapse when selected.

### 5. How does interactivity improve the user experience?

Interactive elements make it easier to navigate the website and explore detailed project information without overwhelming visitors. The expandable sections are especially useful for keeping the Projects page compact.

# Additional Project Documentation 

## Information Organization

My portfolio website is organized into four pages.

- **Home:** Introduces me and highlights my technical skills.
- **Experience:** Shows my education, relevant coursework, achievements, and professional experience.
- **Projects:** Showcases my projects with descriptions, screenshots, technologies used, and GitHub links.
- **Contact:** Provides my email address and links to my GitHub and LinkedIn profiles.

## Visual Design

My visual design uses pink backgrounds, light-colored content cards, darker pink accents, rounded corners, and Poppins typography. Decorative cat illustrations add a playful detail while the page layouts remain structured and easy to follow.

## Interaction and Functionality

- Navigation between the Home, Experience, Projects, and Contact pages
- Expandable Bootstrap accordions for project details
- Project screenshots and links to source repositories
- Links to email, LinkedIn, and GitHub
- Resume PDF viewing and downloading
- Responsive layouts for desktop and mobile screens
- Hover styling for links and buttons

## Technical Overview

- **HTML:** Organizes the content and structure of each page.
- **CSS:** Controls the layout, colors, and styling.
- **JavaScript:** Supports interactive website functionality.
- **Bootstrap:** Provides the expandable accordion components on the Projects page.
- **Flexbox:** Helps organize page layouts.
- **Visual Studio Code:** Used to write and edit the website code.
- **GitHub Desktop:** Used for version control and managing commits.
- **GitHub Pages:** Hosting platform used for the final published website.
